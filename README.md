# ZERO Finance

## Overview

ZERO Finance is a decentralized financial ecosystem focused on permissionless financial protocols and open-access money systems.

The platform empowers users to trade, earn yield, manage liquidity, and access advanced financial products without relying on traditional intermediaries.

---

## Core Products

### ZERO Swap

Decentralized exchange enabling efficient token swaps and liquidity access.

### ZERO Locker

Infrastructure for token locking, vesting schedules, treasury security, and liquidity protection.

### PerpDex

Permissionless perpetual futures exchange supporting leverage trading and advanced market strategies.
